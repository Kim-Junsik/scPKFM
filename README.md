# scPKFM — single-cell Pathway Koopman Flow Matching

조합 유전자 섭동에 대한 단일세포 발현 예측. 학습에서 본 적 없는 **유전자 조합**의
반응을, 그 조합을 이루는 단일 섭동들만 보고 예측한다.

이름의 세 조각이 곧 방법이다. **P**athway — KEGG 경로 주석이 인코더의 어텐션을
게이팅한다. **K**oopman — 잠재 공간에서 섭동마다 전용 선형 연산자로 전개한다.
**F**low **M**atching — 그 연산자를 학습하는 목적함수.

대조군 세포를 인코딩해 잠재 공간에서 섭동별 선형 연산자를 따라 수송한 뒤 디코딩한다.
prior에서 샘플링하지 않으므로, 예측 집단이 대조군 집단의 이질성을 그대로 물려받는다.

```
세포 x [B, G]
  │  ① P-CAB 인코더 — KEGG 경로 토큰이 유전자에 cross-attention
  ▼
잠재 z [B, D]
  │  ② Koopman 속도장  dz/dt = s(t)·(A_a z + b_a),  조합은 Σ_a u_a
  │     RK4 20스텝으로 t: 0 → 1 적분
  ▼
잠재 z₁
  │  ③ E-RCA 디코더 — 같은 마스크를 공유, hurdle 출력 헤드
  ▼
예측 세포 [B, G]
```

---

## 방법

### ① P-CAB 인코더

유전자 전체 self-attention은 O(G²)라 감당이 안 된다(G=5,000이면 셀당 2,500만 쌍).
대신 **K개의 경로 토큰이 유전자에 cross-attention**한다. 비용은 O(G·K). Transformer가
아니다.

생물학적 prior는 마스크로 들어간다:

```
M_total = tanh(M_prior + α · M_residual)     ∈ (−1, 1)^{K×G}
weights = softmax_g(scores) ⊙ M_total        ← 곱셈 게이트
```

`M_prior`는 KEGG 경로-유전자 소속, `M_residual`은 0에서 시작하는 학습 파라미터다.

**곱셈 게이트인 것이 핵심이다.** softmax logit에 더하면 음수 항목이 "덜 주목하라"일
뿐이고 값 집계가 V의 볼록 결합으로 남아, **억제(repression)가 표현 가능한 함수 공간에
아예 없다.** 곱하면 `M_total`이 부호 있는 연결 강도가 되어 음수가 실제로 뺀다. 부수
효과로 마스크 스케일이 불필요해진다 — logit bias였다면 50개짜리 경로가 3,024개의
무관한 유전자를 이기려면 λ ≈ 8이 필요했다.

키와 값을 **그 세포의 발현으로 스케일**하는 것이 attention을 세포별로 만든다. 마스크만
쓰면 모든 세포가 같은 패턴을 받는데, 그건 masked-linear-decoder 계열이 하는 것이다.

KEGG가 덮지 못하는 섭동 대상이 많아(측정: 101개 중 53개가 쓸 만한 경로에 없음 —
발생 전사인자 계열을 KEGG가 목록화하지 않는다) `n_free_tokens`개의 **prior가 전부 0인
토큰**을 덧붙인다. 거기서는 마스크가 `tanh(α·M_residual)`로 줄어 모델이 자기 토큰을
만든다.

### ② Koopman 속도장

섭동마다 전용 선형 연산자를 둔다.

```
u_a(z, t) = s(t) · (A_a z + b_a)          A_a ∈ R^{D×D},  s(t)는 스칼라
```

인코더가 세포를 D차원으로 lifting하고 그 공간에서 선형 연산자로 전개하므로,
Koopman / DMD-with-control 구조다. `s(t)`가 스칼라라 궤적의 모양은 자율 선형계와
같고 진행 속도만 바뀐다.

`A_a`, `b_a`는 **0으로 초기화**한다. 초기 상태에서 모든 생성자가 영(null) 장이 되어,
모델이 노이즈가 아니라 "변화 없음"에서 출발한다.

비교 대상인 비선형 공유 장(`GENERATOR=neural_field`)도 스위치로 남겨뒀다. 설정 절 참조.

> **정확한 서술.** 이것은 Koopman **형식**이지 Koopman autoencoder가 아니다.
> Deep Koopman은 lifting map을 선형 연산자와 **함께** 학습해 잠재 동역학이 선형이
> 되도록 만든다. 여기서는 인코더를 재구성만으로 학습하고 stage 2에서 freeze하므로,
> 잠재 공간이 "재구성에 좋은 공간"이지 "선형화가 성립하는 공간"이 아니다. 논문에는
> *"고정된 재구성 잠재 위의 선형(Koopman 형식) 동역학"*으로 쓸 것.

### 조합은 단순 합이다

```
v(z, t, S) = Σ_{a ∈ S} u_a(z, t)
```

상호작용 항이 없다. 직관과 어긋나므로 근거를 적어둔다.

명시적 대수 상호작용 항(Lie 괄호 `Λ_ab [u_a, u_b]`, 두 섭동 임베딩에 대한 무제약
MLP)을 둘 다 구현해 7개 설정 · 백본 2종 · 유전자 공간 3종 · 지표 6종에서 측정했다.
도움이 되지 않았고, 모델이 제대로 작동하는(resid_R2 > 0) 5개 설정에서는 단순 합이
5전 5승이었다.

원인은 튜닝 실패가 아니라 기계적인 것이다. **상태 의존 장을 적분하는 것은 비선형
연산이므로, 가법 속도장이 이미 비가법 flow map을 만든다:**

```
Φ_ab(z) ≠ Φ_a(z) + Φ_b(z) − z
```

측정: 상호작용 항이 없는 모델이 가법합 대비 0.99 규모의 합성 비가법성을 만들고, 그
잔차가 참 잔차와 코사인 0.46으로 정렬된다. Lie 괄호를 넣으면 같은 코사인이 0.44로
**낮아진다.** 명시적 항은 적분기와 중복이다.

`tests/test_structure.py`가 이 성질을 수치로 검사한다.

실패한 두 항과 조건화 대상이 다른 형태 하나가 스위치로 남아 있다 —
`COMPOSITION=learned`. 설정 절 참조. **아직 측정되지 않았다.**

### 설계 불변식

**어떤 파라미터도 섭동 "쌍"으로 인덱싱되지 않는다.** 이것이 미지의 조합을 예측
가능하게 만든다 — 본 적 있는 쌍만 적합할 수 있는 파라미터가 존재하지 않는다. 쌍
테이블을 쓰던 버전에서는 학습에서 못 본 쌍의 파라미터가 초기값에 머물러 **평가 조건
37개 전부에서 상호작용 항이 정확히 0**이었다. 테스트가 이걸 막는다.

### ③ E-RCA 디코더와 hurdle 헤드

잠재 → 경로 토큰 값 → 유전자별 readout. **인코더와 같은 마스크를 공유한다.**
파라미터 절약이 아니라 부호 일관성 때문이다: 억제 엣지에 대해 디코더는 "경로 상승 →
유전자 하락", 인코더는 "유전자 낮게 관측 → 경로 활성"이라고 말하는데 같은 음수
가중치다. 분리하면 한 엣지에 모순된 부호를 학습할 수 있다.

두 곳에서 밀집 층을 피한다. `latent → (K·d_v)`는 K=277, d_v=64에서 6.3억
파라미터이므로 토큰 임베딩을 조건으로 받는 **공유 소형 MLP**를 토큰마다 평가한다(약
3만). 출력층을 Flatten+Linear로 하면 237억이므로 **공유 방향 벡터 + 유전자별
bias**를 쓴다(약 1.9만). 유전자 정체성은 이미 `h`에 있으므로 잃는 것이 없다.

데이터의 약 41%가 정확히 0이다. 평범한 MSE는 `p(x|z) = N(f(z), σ²I)`로 σ가 상수인
분포를 암묵적으로 고정하고, 추론이 `E[x|z]`를 반환해 세포 간 분산을 붕괴시킨다.
그래서 `x = B · M`으로 나눈다 — `B ~ Bernoulli(검출)`, `M`은 크기. 크기는 검출된
곳에서만 지도한다(0에서도 학습시키면 모든 예측이 0으로 끌려간다).

추론 시 이산 사건은 **샘플링으로 실현**한다(`hurdle_gate=sample`). `soft`(= p·크기)는
조건부 기댓값이라 0이 하나도 안 나오고, `hard`는 p=0.4인 유전자를 모든 세포에서 0으로
만든다. `soft` → `sample` 변경만으로 energy distance가 6.64 → 1.46이었다.

## 학습

2단계다.

**Stage 1 (30 epoch) — 오토인코딩.** VAE. `loss = recon + 1e-3 · KL`, 마스크
residual에 L1 1e-5.

그다음 잠재를 표준화한다(`z = (μ − mean)/std`). 속도장은 이 좌표에서 동작한다.
인코딩은 **청크로** 한다 — 8,192셀을 한 번에 forward하면 학습 배치(256)의 32배짜리
할당이 되어 GPU가 터진다.

**Stage 2 (200 epoch, 앞 60은 단일 섭동만) — 잠재 flow matching.**

VAE는 **freeze한다.** 인코더를 풀면 자명한 최적해가 생긴다 — 잠재를 붕괴시키면
`z₁ − z₀`이 0이 되어 어떤 장이든 완벽한 점수를 받는다. 측정: `‖z₁−z₀‖`이 0.019로
떨어지고 `‖z₀‖`은 ~8을 유지, 수송이 전혀 일어나지 않았다.

```python
z0p, z1p = minibatch_uot(z0, z1)        # 무작위 짝짓기가 아니다
t   = rand(batch, 1)                     # 샘플마다 하나씩
z_t = (1−t)·z0p + t·z1p
loss = mse(v(z_t, t, S), z1p − z0p)
```

**`t`를 샘플마다 뽑는다.** 배치 전체에 스칼라 하나를 쓰면 시간 축 샘플이 스텝당
1개가 되어 [0,1]이 성기게 덮이고, 추론 시 20개 RK4 시점을 지나며 오차가 누적된다.
측정으로 예측 변위가 참값의 72%로 줄었다.

### 집단 통계 손실

flow matching은 속도를 **점별로** 감독한다. 유도된 flow **map**이 어디에 도착하는지,
두 섭동의 map이 어떻게 합성되는지는 손실 어디에도 없다. 그 결과 직접 감독받는 조건이
가장 나쁘게 나온다:

```
train singles 변위 비율   0.646      ← 직접 지도학습
train doubles             0.869
test doubles              1.039      ← 본 적 없음
```

싱글이 35% 짧고 과잉 비가법성이 그 부족분을 메워 조합에서만 1.0이 된다. **두 오차의
상쇄**다. 그래서 두 항을 같이 건다:

```
L = fm  +  w_e · ‖Φ_S(z̄_ctrl) − z̄_S‖²                    (1차: 도착점)
        +  w_r · ‖(Φ_ab − Φ_a − Φ_b + z̄₀) − r_true‖²      (2차: 합성 잔차)
```

한쪽만 막으면 오차가 다른 쪽으로 옮겨간다. **둘 다 쓰거나 둘 다 끌 것.** 타깃은
데이터에서 오는 상수이므로 stage 2 시작 시 한 번만 계산해 캐시한다. 두 항 모두 점
하나를 적분한다 — 집단 평균에 대한 진술이라 같은 것을 감독하면서 비용이 1/batch다.

기본 가중치는 `w_e = 3`, `w_r = 5`. endpoint에 더 큰 값을 주는 이유는 이 과제
신호의 88%가 가법 성분이기 때문이다(순수 가법 ridge가 상호작용 없이 resid_R2 0.53).

측정된 효과: resid_R2 0.0222 → 0.1110, edist_rel 0.3521 → 0.3042.

**한계.** 이 항은 변위 *길이*를 거의 못 고쳤고(0.646 → 0.667) *방향*을
개선했다(gene cosine 0.610 → 0.664). 대조군 **평균 한 점**을 적분하는데 평가는 개별
세포를 적분한 뒤 평균내기 때문이다. 필드가 비선형이라 `Φ(mean) ≠ mean(Φ)`이다.
배치를 적분해 끝점 평균을 맞추면 정확히 같은 양이 되지만 비용이 batch배다.

## 설치와 실행

**1. KEGG 경로 주석 — 필수다.** 저장소에 포함하지 않았다. KEGG는 학술 이용은
무료지만 파일을 재배포하는 것은 별개 허가라, 각자 받는다. REST API에서 가져오므로
로그인이 필요 없다.

```bash
python scripts/download_kegg.py
```

이걸 건너뛰면 P-CAB의 경로 마스크를 만들 수 없어 학습이 시작되지 않는다. 취득일은
`assets/kegg/manifest.json`에 기록된다 — KEGG에 버전 엔드포인트가 없어서 그것이
재현성의 기준점이다.

**2. 데이터 — 필수다.** 용량 때문에 포함하지 않았다.

```
data/norman/norman.h5ad          Norman et al. 조합 섭동 scRNA-seq
data/norman/split_results.pkl    5-fold 분할. 데이터와 함께 배포되는 파일
```

**3. 실행.**

```bash
sh run.sh
```

캐시 생성 → 학습 → 지표 → transport 진단 → cell-eval → 논문 표까지 한 번에 돈다.
`--eval-only`로 학습을 건너뛰고, `--no-celleval`로 채점(약 30분)을 생략한다.

cell-eval은 의존성이 이 프로젝트와 충돌해서 자기 인터프리터를 쓴다. 없으면 `run.sh`가
첫 실행에서 `scripts/setup_celleval_linux.sh`로 만든다. 실패해도 학습과 나머지 지표는
그대로 나오고, 논문 표의 다섯 열만 `-`로 남는다.

**`TAG`를 매 실험마다 바꿀 것.** 학습 스크립트가 디렉터리를 `exist_ok=True`로 열고
`checkpoint.pt`를 경고 없이 덮어쓴다. `run.sh`에 가드가 있지만 태그를 구분하는 것은
사용자 몫이다.

| 키 | 기본 | 의미 |
|---|---|---|
| `FOLD` | 1 | 0–4. **fold를 섞지 말 것** (아래 참조) |
| `N_HVG` / `HVG_CRITERION` | 5000 / scanpy | `sc.pp.highly_variable_genes`의 seurat 기본값 |
| `STRICT_SPLIT` | true | 유전자 선택에서도 held-out 조건 배제 |
| `ENDPOINT_WEIGHT` / `RESID_WEIGHT` | 3 / 5 | 집단 통계 손실. 둘 다 켜거나 둘 다 끄기 |
| `GENERATOR` | affine | `affine` \| `neural_field` |
| `COMPOSITION` | additive | `additive` \| `learned` |
| `LATENT_READOUT` | dense | `dense` \| `pathway` |
| `GENERATOR_RANK` | null | `A_a = U_a V_a`의 rank |

### `GENERATOR`

섭동 하나의 속도장 `u_a(z, t)`를 만드는 방법. 두 구현이 **같은 자리**를 채운다.

| | `affine` (기본) | `neural_field` |
|---|---|---|
| 형태 | `s(t)·(A_a z + b_a)` — 선형 | `f([z, φ(t), e_a])` — 비선형 MLP |
| 섭동별 전용 파라미터 | **4,160** (64×64 행렬 + 편향) | **32** (임베딩만) |
| 공유되는 것 | 시간 스케일뿐 | trunk + head 전부 |
| field 총 파라미터 | 421 K | 120 K |

`affine`은 섭동마다 독립된 연산자를 주고, `neural_field`는 101개 섭동을 32차원
임베딩으로 구분해 **하나의 함수**에 통과시킨다. 대비되는 축은 깊이가 아니라
**섭동별 전용 용량**이고, 그 비율이 130배다.

fold 0에서 나머지를 전부 고정하고 이 축만 바꾼 결과:

| 백본 | affine | neural_field | 차이 |
|---|---|---|---|
| mlp | 0.3348 | −0.4377 | **+0.77** |
| pcab | 0.1965 | −0.1346 | **+0.33** |

**더 표현력 있는 쪽이 졌다.** 그래서 용량이 병목이었다고 읽는 것이지만, 두 팔이
**용량과 함수 형태(선형/비선형)를 동시에** 바꾸므로 귀속이 분리되지는 않았다.
분리하려면 세 번째 팔(섭동별 전용 MLP)이 필요한데 만든 적이 없다.

그리고 **fold 1이나 집단 통계 손실 하에서는 비교한 적이 없다.** 스위치를 남겨둔
이유가 그것이다. 실행 디렉터리 이름에 generator가 들어가므로
(`${TAG}_${GENERATOR}_f${FOLD}`) 두 결과가 섞이지 않는다.

`neural_field`에는 `GENERATOR_RANK`가 의미 없다(아핀 연산자를 인수분해하는
옵션이므로). 같이 주면 에러가 난다.

### `COMPOSITION`

두 섭동의 필드를 어떻게 합칠지.

```
additive   v = Σ u_a
learned    v = Σ u_a + ρ( Σ φ(u_a) )
```

선형 생성자 둘을 합성하면 BCH 공식이 나온다:

```
log(e^A e^B) = A + B + ½[A,B] + (고차항…)
```

`additive`는 1차에서 자르고, 이미 실패한 Lie 괄호 항은 2차에서 잘랐다. `learned`는
자르지 않고 **나머지를 학습**한다.

**이미 실패한 두 항과 다른 점**은 무엇에 조건화하느냐다. Lie 괄호와 free MLP는 둘 다
**섭동 정체성**(어느 유전자를 건드렸는가)을 보고 보정을 만들었다. `learned`는 생성자가
그 지점에서 실제로 **낸 속도 벡터**를 본다. 미지 조합에는 익숙한 정체성 쌍이 없지만
속도는 학습 때와 똑같이 계산되므로, 보정이 같은 토대 위에 선다.

구조적으로 보장되는 것:

- `φ`를 섭동마다 적용해 **더하므로**(DeepSets) 순서에 의존할 수 없다
- 섭동으로 인덱싱되는 파라미터가 없다 — 쌍은 물론이고 단일도
- `ρ`의 출력층이 0에서 시작하므로 **학습 시작이 정확히 가법**이다. 최종 점수 차이가
  초기화가 아니라 이 항 때문이라고 말할 수 있는 유일한 방법이다
- `|S| ≥ 2`일 때만 적용되므로 단일 섭동은 여전히 정확히 자기 생성자다

`tests/test_structure.py`가 네 가지를 전부 검사하고, 여기에 두 개를 더 본다 —
초기에 가법과 정확히 일치하는지, 그리고 `ρ`가 0이 아니게 되면 실제로 달라지는지.
후자는 **배선은 됐는데 수치적으로 죽어 있는 항**에 대한 방어다. `[P, P]` 상호작용
테이블이 정확히 그렇게 실패했다.

> **아직 측정되지 않았다.** 이 모델에 구조적 항을 세 번 얹었고(Lie 괄호, free MLP,
> Koopman 자체) 어느 것도 개선하지 못했다. 가설에 스위치를 달아둔 것이지 기본값이
> 아니다.

### `LATENT_READOUT`

`dense`에서 잠재는 `Linear(K·d_v → 64)`로 만들어진다. 생물학적 구조는 **인코딩
경로**에 있지만(어떤 유전자가 어떤 토큰에 기여하는지), 밀집 투영이 토큰을 섞으므로
64차원 잠재의 각 차원은 특정 경로에 대응하지 않고 `A_a`도 읽을 수 없다.

`pathway`는 토큰별 readout(`z_k = ⟨h_k, w⟩ + b_k`)을 쓴다. `latent_dim`이 **K가
되고 차원 k가 곧 경로 k**이므로, Koopman 연산자가 읽을 수 있는 행렬이 된다:

```
A_a[i, j] = 섭동 a 하에서 경로 j의 활성이 경로 i를 구동하는 정도
```

`field.generator.matrix(a)`로 꺼낸다. 마스크의 `learned_edges()`(데이터가 더하거나
뺀 엣지)와 함께 놓으면 해석 가능성이 결과물이 된다.

> **이 옵션은 정확도를 올린다는 근거가 없다.** 오히려 측정이 반대를 가리킨다 —
> 64차원 병목은 무죄로 판정됐다(잔차의 신호 내 비중이 잠재 0.575 vs 유전자공간
> 0.393). 병목이 정보를 지우지 않으므로 넓혀서 얻을 것이 없고 잃을 수는 있다.
> **사는 것은 해석 가능성이다.** 그리고 K의 상당 부분이 자유 토큰이라 **그 차원들은
> 경로가 아니다** — 주석 블록과 자유 블록을 나눠서 보고할 것.

### `GENERATOR_RANK`

| 설정 | `A_a` 크기 | 섭동 101개 총합 |
|---|---|---|
| dense (D=64) | 4,160 | 421 K |
| pathway (K≈272) | 74,000 | 7.5 M |
| pathway + rank 16 | 8,704 | 879 K |

`pathway`를 쓰면 rank도 같이 쓰는 편이 현실적이다.

구현 주의: `U`만 0으로 초기화하고 `V`는 작은 난수다. 둘 다 0이면 곱의 그래디언트가
양쪽 모두 소멸해 연산자가 원점을 못 벗어난다. 초기 필드가 정확히 영이라는 성질은
그대로 유지된다.

## 평가

### 지표

| | 뜻 | 방향 |
|---|---|---|
| `resid_R2` (pooled) | 비가법 잔차 복원. **0점 = `m_A + m_B − m_ctrl` 산수와 동률** | ↑ |
| `edist_rel` | 예측/실제 energy distance ÷ 대조군/실제. 0이면 완벽, 1이면 대조군 수준 | ↓ |
| L2, MSE, MAE, DE-Spearman, Pearson Δ, DS | 문헌이 보고하는 8열 중 6개 | — |

`resid_R2`를 조건별로 계산할 때는 분모 `‖r‖² − e_noise`가 0 근처로 가면 비율이
폭발한다(조건 크기가 46–1,005셀로 20배 차이난다). 분모가 양수이고 노이즈 바닥의
2배 이상일 때만 채점하고, **pooled 값을 인용할 것.** 조건별 평균은 불안정하다 —
같은 run에서 pooled −1.12, 조건별 평균 −2.89로 2.6배 벌어진 적이 있다.

`Pearson Δ̂`, `Δ̂₂₀`는 이 프로토콜에서 **정의되지 않는다.** 학습셋 안의 섭동 p의
중심을 필요로 하는데 조합 홀드아웃에서는 평가 대상 p가 학습에 없고, 예측이 대조군
세포를 수송하는 방식이라 세포 간 대응도 없다. 누락이 아니라 부재이므로 n/a로 싣고
각주를 달 것.

### 반드시 함께 보고할 베이스라인

fold 1 기준:

| | resid_R2 ↑ | edist_rel ↓ |
|---|---|---|
| control | −2.8750 | 1.0000 |
| additive `m_A + m_B − m_ctrl` | 0.0000 | 0.5662 |
| pairwise_ridge | 0.2068 | 0.3563 |
| per_gene_scaled | 0.3831 | 0.3782 |
| **ridge_additive** | **0.5329** | **0.2927** |

`ridge_additive`가 진짜 상대다. **상호작용을 전혀 모델링하지 않고** 섭동별 효과
벡터를 ridge로 적합해 `w_A + w_B`를 내는 것만으로 0.5329를 낸다. 조건들 사이로
정보를 모아 단일 효과의 노이즈를 제거하기 때문이다. 학습 조건으로만 적합하고
alpha는 test를 보지 말 것.

### fold를 섞지 말 것

**같은 베이스라인이 fold에 따라 resid_R2가 0.47 움직인다.**

```
ridge_additive:  fold0 0.4645  fold1 0.5329  fold2 0.2656  fold3 0.0628  fold4 0.2596
```

`pairwise_ridge`는 부호까지 뒤집힌다(+0.24 ↔ −0.26). 이 편차는 지금까지 측정된 어떤
모델 간 격차보다 크다. **모델 점수를 다른 fold의 베이스라인과 비교하면 안 된다.**
fold 1이 가장 쉬운 fold이고, 선행 연구가 관행적으로 쓰는 fold이기도 하다.

### 누수 제거

held-out 조건의 세포가 세 곳 어디에도 들어가지 않는다: 인코더 학습, 잠재 표준화
통계, **유전자 선택**. 학습 로그의 이 줄이 증거다.

```
cells visible to training: 75,897 / 84,986  (9,089 held-out cells excluded)
```

선행 파이프라인은 전체 데이터에서 HVG를 고르므로 세 번째를 하지 않는다. **더 엄격한
문제를 푸는 것이므로 논문에 그렇게 명시할 것.** 밝히지 않으면 부정확한 비교이고,
밝히면 격차의 일부가 설명된다.

## 테스트

```bash
python -m pytest tests/test_structure.py -v
```

정확도 테스트가 아니다. 학습 없이 성립해야 하는 성질을 검사하므로, 실패하면 "학습이
부족하다"가 아니라 **합성이 틀렸다**는 뜻이다. 대조군에서 속도장이 정확히 0인지,
조합이 정확히 생성자들의 합인지, 순열 불변인지, 쌍으로 인덱싱된 파라미터가 없는지,
그리고 가법 속도장인데도 flow map이 비가법인지를 확인한다.

`tests/test_splits.py`는 `data/`가 있어야 돈다.
